# PYLA Developer Context

This directory is the developer-facing source of truth for PYLA's architecture,
design constraints, current capabilities, and roadmap.

## Documents

- `architecture.md` - system boundaries and crate responsibilities
- `execution-model.md` - analysis, planning, validation, rollback, and worktrees
- `language-adapters.md` - adapter contract and supported languages
- `cli.md` - command reference and JSON output
- `safety.md` - trust boundaries and non-negotiable safety rules
- `roadmap.md` - implemented work and next milestones

PYLA is deterministic and AI-free. Documentation must not describe generated
code as semantically correct unless behavior has been validated.
